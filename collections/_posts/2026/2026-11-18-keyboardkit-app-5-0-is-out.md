Version 5.0 of the [KeyboardKit app](/app) is out! This is a big update, with more reliable typing, improved iPhone Duo support, new actions, and a brand new GIF keyboard.

This version uses [KeyboardKit 11.2]({{page.release}}), which means that it gets all the latest features and improvements. See that post for more details about everything new.


## Improved Typing

The keyboard has been adjusted to reduce the risk of stuck and lost key presses. Previously, a key gesture could be dropped if a key changed while typing. Keys now keep their touches, which makes typing more responsive.


## iPhone Duo

The app keeps getting better on the [iPhone Duo]({{page.post-duo}}). When the Duo is unfolded in landscape, the keyboard now has a new button that lets you change the keyboard placement, for instance between a full and split keyboard.


## GIFs

You can now find and send GIFs, right from the keyboard! Just search for a GIF and tap it to copy it, then paste it into the current app. The app uses [KLIPY](https://klipy.com), and supports a keyboard and toolbar placement.


## Themes

Your favorite themes have moved from the main menu to the themes screen, which makes it easier to manage the themes you use the most.


## New Actions

You can now add GIF keyboard toggles to the keyboard and its toolbars. This lets you jump to the GIF keyboard with a single tap, from wherever you want it to be.


## Conclusion

KeyboardKit app 5.0 makes typing more reliable, improves the iPhone Duo experience, and adds a brand new GIF keyboard. Download it from the [App Store]({{site.urls.appstore}}) today, and let us know what you think.
