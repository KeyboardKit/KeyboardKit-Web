The first KeyboardKit 11 documentation is now available as a downloadable DocC documentation archive from the [beta release page]({{page.release}}).


## Documentation Changes

The KeyboardKit 11 documentation is updated with regards to the removed, deprecated code, and all the new features in the next major KeyboardKit release.

For instance, the documentation has been updated with information on how to enable host application resolving with the new `KeyboardKitHostPlugin` and dictation with the new `KeyboardKitDictationPlugin`.

Since the SDK is simplified in KeyboardKit 11, the updated documentation also removes some developer guides, and instead simplifies the information and puts it directly in the feature article.


## Expected Release

The [online documentation]({{site.urls.docs}}) is still built for KeyboardKit 10, but the updated documentation will replace it as soon as KeyboardKit 11 is released.

We expect to release KeyboardKit 11.0 on October 1st. Don't hesistate to [reach out]({{site.urls.email}}) if you have any feedback on the [beta release]({{page.release}}) or the new documentation.
